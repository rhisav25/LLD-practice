# Low-Level Design (LLD) Practice

This repository contains simple and modular **Low-Level Design (LLD)** implementations for common interview questions.  
The goal is to cover the basics of clean object-oriented design needed for **SDE-1 / entry-level** interviews.

Each problem is implemented with:

- **Clear OOP structure**
- **SOLID principles**
- **Small, modular classes**
- **Easy-to-understand flow**
- **Java implementations**

## 🧩 Design Approach

All implementations follow:

### **OOP Principles**
- Encapsulation  
- Abstraction  
- Inheritance (only when needed)  
- Polymorphism  

### **SOLID Principles**
- **S**ingle Responsibility — each class has one job  
- **O**pen/Closed — easy to extend, hard to break  
- **L**iskov Substitution — interfaces used correctly  
- **I**nterface Segregation — small focused interfaces  
- **D**ependency Inversion — high-level modules depend on abstractions
